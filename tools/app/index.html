Turn your export into a dashboard

Drop a Jira issues CSV, your Etsy Order Items / payments statement CSV, or a biometric attendance export (eSSL, ZKTeco) here. You get KPIs, findings in plain English and a summary to share.

🔒 Your file never leaves your device: everything is calculated in this browser tab. No upload, no account.

How to export from Jira

Jira Cloud: Filters → View all issues (or Search), switch to the list view, then Export → Export CSV (current fields) or (all fields). Jira Server/Data Center: Issues → Search for issues → Export → CSV. Up to 10,000 issues per export on Jira Cloud.

How to export from Etsy

Order Items: Shop Manager → Settings → Options → Download Data → Orders: Order Items → Download CSV. Payments statement: Shop Manager → Finances → Monthly statements → Download CSV. Drop one or both files.

How to export attendance

eSSL eTimeTrackLite: Reports → Daily Attendance (or Monthly In/Out) → Export to Excel, then in Excel File → Save As → CSV. ZKTeco / BioTime: Attendance → Transactions → Export → CSV. A punch log (one row per punch) or a daily In/Out report both work; the columns are found by their names.
