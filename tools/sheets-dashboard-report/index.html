Google Sheets add-on

Sheet to Dashboard Report

Turn the table in your sheet into a dashboard report your team can read in a minute: KPI cards with good / warning / problem colours, charts that explain themselves, key findings in plain English and bordered tables. Free, no sign-up, and your data stays in your spreadsheet.

Coming soon The add-on is waiting for Google Workspace Marketplace approval. This page will link to the Marketplace listing as soon as it is live.

Contents: What it does · Install · How to use it · Report types · Limits · Permissions · Privacy · Support

What it does

The add-on reads the table in the sheet you have open (or your selection) and builds a dashboard report in a window inside Google Sheets. It recognises Jira, Etsy and attendance exports by their column names and gives them tailored reports; any other table gets a general summary. It uses the same report engine as our free CSV to Dashboard web tool.

  • Download HTML report: one HTML file with the whole report. It opens in any browser, offline, and contains no scripts, so you can email it or attach it to a ticket.
  • Copy KPIs to a new sheet: adds a sheet named “Report KPIs” with the report’s headline numbers, as plain values.

Install

Coming soon Once Google approves the add-on:

  1. Open a spreadsheet in Google Sheets.
  2. Choose Extensions → Add-ons → Get add-ons and search for Sheet to Dashboard Report.
  3. Click Install and review the two permissions (explained below).

A Google Workspace administrator can also install it for a whole domain from the Marketplace.

How to use it

  1. Open your sheet. The first row must hold the column names, with one record per row below. The table can start lower down or further right: blank rows and columns are skipped.
  2. Choose Extensions → Sheet to Dashboard Report → Open. The sidebar opens on the right.
  3. Under Data, choose Whole sheet or Current selection. If you change the sheet or the selection while the sidebar is open, click Refresh.
  4. Leave Report type on Auto-detect from the column names, or pick one.
  5. Optionally open More options: a report title, a second sheet for Etsy (order items and statement together), the Jira issue type (empty = Bug, * = all types), the Etsy product cost as a % of sales, and the attendance shift start and end, grace minutes and weekly off.
  6. Click Build report. The report opens in a window; from there you can download it or copy the KPIs.

Limits

  • Free. The report covers the first 5,000 rows of a sheet or selection; the sidebar and the report say so when a table is longer.
  • One kind of export per report (two sheets only for Etsy’s order items + statement).
  • Dates are read as Sheets stores them, in the spreadsheet’s time zone. Numbers and money keep the format shown in the cells.

Permissions, in plain words

The add-on asks for two permissions and nothing else:

What Google shows on the consent screenWhy the add-on needs it
See, edit, create and delete only the specific Google Sheets spreadsheets that you use this app with
spreadsheets.currentonly		To read the table you choose in the spreadsheet you have open. It is also used to add one sheet named “Report KPIs” to that same spreadsheet, and only when you click Copy KPIs to a new sheet. It gives no access to your Google Drive or to any other file.
Display and run third-party web content in prompts and sidebars inside Google applications
script.container.ui		To show the add-on’s sidebar (the report options) and the report window inside Google Sheets.

It has no Google Drive permission, no permission to connect to outside services, and no access to your email, contacts or other files.

Privacy

  • Your data stays in your spreadsheet and the report window. The add-on reads the cells inside Google and builds the report in your browser window. Nothing is sent to VPC Apps or anyone else, and nothing is stored, logged, or used for advertising or AI training.
  • The add-on reads only the sheet or selection you choose, only while you use it.
  • A downloaded report is a file on your device; where it goes is up to you.
