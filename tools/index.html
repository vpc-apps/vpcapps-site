How it works

  1. Export a CSV from the tool you already use (Jira, Etsy, your attendance machine).
  2. Drop it on the page. The format is recognised and the numbers appear in a second.
  3. Adjust the settings, then download a one-file HTML summary or print it as a PDF.

Free, private, offline

  • Free. Reads the first 5,000 rows of each file.
  • No upload: the file is read by your own browser, so it suits work and staff data. The pages only count anonymous visits (Cloudflare Web Analytics, no cookies, never your file).
  • Works offline after your first visit. In Chrome or Edge you can install it as an app from the address bar.
