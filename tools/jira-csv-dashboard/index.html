Turn a Jira CSV export into a QA dashboard

Export your issues from Jira, drop the CSV here and get a bug and QA status dashboard in seconds: open vs resolved trend, ageing, priorities, assignees and components, with plain-English findings and a one-page summary you can send to your manager.

What you get

  • Six headline numbers: issues, open, resolved, median time to resolve, high-priority issues open over 30 days, unassigned open issues.
  • Findings written out for you: whether the backlog grew in the last 4 weeks, old high-priority bugs, and whether one person holds too many open issues.
  • Charts: created vs resolved per week, age of open issues, open by priority, assignee, component and status, issues by fix version.
  • Filters for issue type (Bugs by default) and project, plus a breakdown by one of your custom fields such as Severity or Root cause.
  • A one-file HTML summary (no scripts, opens anywhere, easy to email) and a print-ready PDF layout.

How to export the file

  1. In Jira Cloud open Filters → View all issues (or run a search with the JQL you need) and switch to the list view.
  2. Choose Export → Export CSV (all fields) or (current fields). Current fields is faster; make sure Status, Priority, Created, Resolved and Assignee are visible.
  3. Jira Server or Data Center: Issues → Search for issues → Export → CSV.
  4. Drop the file above. Jira Cloud exports up to 10,000 issues per file.

Your file never leaves your device

The tool is a web page that runs entirely in your browser. When you choose a file, it is read and analysed on your computer: nothing is uploaded, stored or seen by us. After your first visit it also works with no internet connection. See our privacy policy.

Questions

Is my Jira data uploaded anywhere?

No. The CSV is read and analysed by JavaScript in your own browser tab. Nothing is sent to us or to any server, so it suits confidential projects, and it keeps working offline after your first visit.

Which Jira exports work?

Jira Cloud, Server and Data Center issue exports in CSV, with all fields or current fields. Columns are found by their names, so the order doesn't matter, and multi-value fields like Labels, Sprint and Comment that Jira repeats in several columns are merged.

How many issues can I analyse?

The free version reads the first 5,000 rows of each file. Jira Cloud exports up to 10,000 issues at a time; for bigger projects, export one file per quarter or per project.

Can I break the numbers down by a custom field?

Yes. Custom fields appear in the export as "Custom field (Name)". Pick one, such as Severity, Root cause or Environment, under "Extra breakdown" to see open issues by that field.

How do I share the report?

Use "Download summary (HTML)" for a single file you can attach to an email, or "Print / PDF" and save as PDF. The free version adds a small "made with" line at the bottom.
